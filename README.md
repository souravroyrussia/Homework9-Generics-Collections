# Homework 9 — Generics and Collections

Java 21 project containing both exercises from the assignment.

- Exercise 1: Investor portfolio, purchase queue, positions by ticker, total value, grouping by instrument type.
- Exercise 2: Generic warehouse base class, regular and VIP queues, sack grouping and empty types, box sorting and fragile count.

Open this folder in IntelliJ IDEA and run `src/Main.java`.
